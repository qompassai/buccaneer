# buccaneer

An autonomous AI penetration-testing agent written in Rust —
rose-local models by default, a deterministic authorization gate
over declared scope, MCP-native tooling, and no telemetry.

Status: the name is reserved on crates.io (v0.1.0); implementation
is in development. Releases publish via crates.io Trusted
Publishing (OpenID Connect) from this repository.
